# 无人机红外与模拟距离回波直方图融合：研究方案草案

更新日期：2026-09-20。状态：用户已同意按现有倾斜下视参数推进；新增配对雷达点云代理路线分析。尚未实施或得到实验结果。

## 1. 已确认的目标与约束

- 场景：无人机倾斜向下观测地面车辆，进行检测与跟踪。
- 图像模态：红外图像，初期使用公开数据。
- 雷达输入：单周期 200 个回波分布在 N 个距离区间，N 为 128 或 256；每个值为非负整数，所有区间计数之和为 200。
- 初期使用模拟雷达，研究特征级融合；真实雷达泛化不属于初期实验可以证明的结论。
- 首先验证检测，具备连续序列及轨迹 ID 后再评价跟踪。

## 2. 尚待确认及暂定假设

初期暂定相机与雷达同机、近似共址、同步，地面为平面。真实安装外参、视场和时间偏差作为后续扰动。

用户已确认倾斜向下观测。第一阶段的几何检查默认高度 60 m、相对水平面向下 45°、水平视场角 60°、距离范围 [0,256) m，均为可配置仿真假设，不是实测参数。飞行高度、相机内参、量程、距离区间宽度、车辆高度和周期时长均需在相应实验配置中明确记录。静态模拟阶段不使用周期时长；进入时序模拟前必须定义它。缺少真实元数据时不能冒充实测值。

先统一检测“车辆”一类。具体车型区分和旋转框作为后续选择；转换框格式时保留原始标注并记录转换规则。

## 3. 数据路线和证据边界

采用两条互补路线：无人机红外与统计模拟用于受控验证；真实配对红外与毫米波检测点云汇聚用于检查真实跨模态信息。后者优先核验 FlexSense，详细分析见 [配对雷达可行性报告](paired-radar-feasibility.md)。点云汇聚/重采样不能恢复原始回波，不改变路侧数据的采集视角。

候选红外检测数据为 DroneVehicle 的红外部分，正式选定前检查下载、许可、划分和标注。
官方来源：https://github.com/VisDrone/DroneVehicle

第一阶段允许使用图像标注和假设几何生成对应的雷达代理输入。该输入利用了人工标签提供的信息，属于理想化、标签条件化的模拟，存在人为引入有利信息的风险。其融合增益仅能表明网络在该模拟条件下可利用辅助输入，不能证明真实雷达有效，也不能据此宣称标签泄漏问题已解决。

更可信的后续路线是使用同一个三维场景、车辆状态和传感器位姿，分别生成红外观测、雷达观测与标签；传感器模拟器不直接读取检测框或类别答案。即便如此，结论仍受渲染与雷达模型的逼真程度限制。

不能将随机直方图与任意图像配对后称为有效的融合数据；随机输入仅作为对照。

## 4. 模拟雷达生成规则

### 4.1 几何与距离

通过相机内参和姿态将图像位置解释为射线，与假设地面相交，得到候选三维位置；利用雷达位置计算斜距。检测框中心只是目标位置的近似，车辆高度、框中心偏移和地面起伏引入位置不确定性。

没有相机内参或高度时，必须显式配置假设值，并对这些值做敏感性实验。不得将图像纵坐标直接当作真实距离。

缺少角度的距离直方图不能唯一确定图像中的车辆。同距离车辆可产生重叠回波。地面和其他背景也可以形成峰，不能规定所有峰均来自车辆。

### 4.2 200 个回波的统计模型

构造离散距离分布：

    p = w_target * p_target + w_ground * p_ground + w_clutter * p_clutter
    w_target + w_ground + w_clutter = 1
    n ~ Multinomial(200, p)

其中车辆分量由多个带展宽的距离分布混合构成，权重与车辆数量或尺寸不作精确的一一对应；地面分量由照射范围和假设几何产生；杂波分量包含宽背景及随机局部峰。无车辆时，车辆权重设为零，其余分量重新归一化。

这是统计代理模型，不是毫米波电磁传播或完整波形仿真。固定 200 表示在总计数已给定条件下生成分布，不推断实际发射、漏收与回波选择机制。

随机因素包括目标分量缺失、背景峰、距离偏差、峰宽变化、车辆与背景回波占比变化。目标漏检通过减少或移除目标分量并重新分配计数实现，仍保持总数为 200。

先选定共同物理量程生成 256 桶，再将相邻两桶相加获得 128 桶，保证两种输入表示相同的 200 个回波。只有量程和区间边界兼容时才能采用此规则。

### 4.3 保存的字段

- image_id、sequence_id（若存在）、timestamp（若存在）。
- counts、bin_edges_m、echo_count=200。
- 仿真假设的高度、姿态、内参、外参、噪声参数、随机种子及生成器版本。
- 数据来源标识：标签条件化代理 / 三维场景仿真 / 点云经验分布重采样 / 真实原生直方图。
- 点云路线额外保存原始计数、实际有效点数、视场裁取规则和雷达有效性；空帧不能强行伪造 200 个计数。
- 标签单独保存；真实或假设的目标距离不得通过调试字段进入模型输入。

原始计数必须保留。模型可使用 counts / 200 和距离位置编码。

## 5. 第一版网络与对照

红外图像经二维编码器获得空间特征。雷达直方图经轻量一维卷积编码，使用距离位置编码保留物理位置，再生成通道调节参数，完成中间特征融合和车辆检测。

第一版采用残差式门控融合，并明确雷达缺失标记；缺失时回退到图像路径。全局门控不宣称逐车距离关联，初版不输出未经监督验证的车辆距离。

必要对照：

1. 仅红外检测器。
2. 参数规模尽量匹配的仅红外模型，用于排除增加模型容量带来的收益。
3. 红外 + 简单融合。
4. 红外 + 门控融合。
5. 对已训练的融合模型，分别输入正确配对、跨样本打乱、固定背景及缺失雷达，检查依赖关系。

打乱雷达应尽量在相同高度、姿态等场景条件内进行，减少场景分布变化造成的混淆。它仍不能消除标签条件化模拟本身的乐观偏差。

## 6. 评价与分阶段交付

| 阶段 | 交付物 | 验收方式 |
| --- | --- | --- |
| A 数据审查与模拟可视化 | 图像、车辆框、对应距离直方图及参数记录 | 检查形状、非负整数、总数、物理距离与同距离重叠等情况 |
| B 红外基线 | 可复现训练配置、权重和评价报告 | 小样本过拟合用于调试；独立验证集用于性能判断 |
| C 融合检测 | 一维编码器、融合模块及对照实验 | 同一划分和训练预算比较 mAP、召回率与误报 |
| D 鲁棒性 | 不同背景强度、距离误差、回波占比和模态缺失实验 | 检查增益是否仅出现在理想条件，以及何时反而退化 |
| E 时序与跟踪 | 有连续 ID 标注的序列、跟踪基线及融合改进 | HOTA、IDF1、ID 切换；处理无人机自运动与模态时间偏差 |

按源场景或完整序列划分数据，再生成模拟样本。不得将同一图像的不同雷达随机种子版本分到训练和测试两侧。遵守数据集现有划分，并在可获得元数据时检查近重复帧。

固定基准测试参数和种子；调参仅使用训练/验证集。正式结论报告多个训练种子的结果与波动，不预设必须取得提升。

模拟测试应包含训练范围之外的参数组合，但不能把同一模拟器的分布外实验等同于真实域验证。

跟踪数据必须保留实际时间顺序及 ID；不得将独立检测图片随意排序生成跟踪评估。时序模拟需维持车辆运动和背景的连续性，不能每帧独立重置整套场景参数。
