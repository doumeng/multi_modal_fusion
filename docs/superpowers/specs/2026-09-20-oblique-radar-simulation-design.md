# 倾斜下视距离直方图模拟：首阶段设计

日期：2026-09-20。状态：用户已同意按现有参数推进；未实现。配对毫米波点云路线另见 ../../paired-radar-feasibility.md，作为互补数据路线，不改变本阶段模拟器的参数。

## 目标与范围

已确认：无人机倾斜向下观测地面车辆；融合红外与一维距离计数直方图，最终实现检测与跟踪；先用模拟雷达验证。每周期恰有 200 个回波，分配到 128 或 256 个距离区间。

本阶段只交付可复现的几何计算、统计回波生成、数据接口及可视化。暂不训练检测网络、不宣称融合有效、不评价跟踪。整体研究路线见 ../../research-plan.md。

## 方案选择

1. 推荐起步方案：对公开红外图像中的车辆标注使用假设几何，生成标签条件化雷达代理。成本较低，适合检查数据和网络接口，但具有乐观偏差。
2. 后续增强方案：同一三维场景分别产生红外、雷达与标签，减少直接从检测框构造输入的问题；需要更大的建模投入。
3. 任意随机直方图只用作负对照，不作为配对训练数据来源。

先采用方案 1，并用少量明确标注为合成示意的场景做几何单元验证。示意图不冒充真实红外图像。

## 默认几何（假设值，全部可配置）

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 高度 | 60 m | 相对平面地面 |
| 下视角 theta | 45° | 相对水平面向下；90° 才是垂直俯视 |
| 水平视场角 | 60° | 无真实内参时的代理值 |
| 相机 | 针孔、方形像素、零畸变 | 主点位于图像中心；垂直视场由宽高比导出 |
| 雷达外参 | 与相机共址、共轴 | 不是实际安装条件的断言 |
| 雷达照射范围 | 暂与相机视场一致 | 无实际天线方向图，不能等同于真实雷达波束 |
| 距离区间 | [0,256) m | 256 桶时 1 m/桶；128 桶时 2 m/桶 |
| 回波总数 | 200 | 量程和视场内、已筛选回波的条件分布 |

默认值用于可复现演示，不作为特定硬件选型建议。公开图像无姿态/高度信息时，假设值无法恢复真实距离；生成结果始终标为代理数据。不能对不同实拍姿态的图片声称使用同一组参数就完成了标定。

## 射线与地面求交

相机坐标采用 x 向右、y 向下、z 向前。世界坐标采用 X 向右、Y 向前、Z 向上，地面 Z=0，相机中心 C=(0,0,h)。初始无偏航、无横滚。

以像素中心为整数坐标，主点 cx=(W-1)/2、cy=(H-1)/2，fx=fy=W/(2*tan(HFOV/2))。对像素 (u,v)：

    x=(u-cx)/fx, y=(v-cy)/fy
    d=(x, cos(theta)-y*sin(theta), -sin(theta)-y*cos(theta))
    t=-h/d_z
    P=C+t*d
    range=norm(P-C)

d 不要求归一化；range 必须由向量长度计算，不可直接将 t 当作距离。仅接受 d_z < -1e-8、t>0 且有限的交点。中心射线斜距应为 h/sin(theta)，默认约 84.85 m，地面向前距离约 60 m。

车辆标注中心仅作为地面位置代理，不能代表精确车辆接地点。首版车辆采用地面点近似，不建三维车身；用距离扰动和峰展宽体现近似误差，后续再添加车辆高度。

图像增强必须维护几何：裁剪/缩放同步更新内参或保留原图坐标映射；首阶段先在原始坐标生成直方图。不得独立裁剪图像后声称雷达视场也自动完成裁剪。

## 统计回波模型

在 256 个距离区间上构造并归一化以下分量：

- 车辆分量：以有效且量程内的车辆斜距为中心的高斯核混合，默认核标准差 2 m；初始各车辆权重相同，后续可随机扰动。该权重不是 RCS 估计。
- 地面分量：在图像视场内均匀抽取 4096 条像素射线，投到地面，按斜距形成分布。它是视场几何背景代理，不是辐射定标或物理散射模型。
- 杂波分量：量程内均匀背景与两个随机局部高斯峰等权混合，峰位置来自独立随机数，默认标准差 4 m。杂波不读取车辆标签。

基准混合权重依次为 0.3、0.6、0.1，仅作为受控实验起点。不存在有效车辆时设车辆权重为零，其余权重重新归一化，不生成虚假的目标分量。有有效车辆时可配置目标分量随机缺失概率，基准为零，鲁棒性配置另行显式指定。

    p = normalize(w_target*p_target + w_ground*p_ground + w_clutter*p_clutter)
    counts_256 ~ Multinomial(200, p)
    counts_128[j] = counts_256[2*j] + counts_256[2*j+1]

车辆在雷达量程外或射线无有效交点时不生成该车辆雷达分量；保留图像检测标签并记录原因，不将距离强行夹到边界桶。高斯核仅在有效量程内归一化，记录截断条件。

地面视场与量程完全没有交集时拒绝该配置并给出原因，避免用纯杂波掩盖错误几何。负高度、无效角度、非有限参数、负混合权重或零总权重均直接报错。

对照集至少覆盖背景主导（权重 0.1/0.8/0.1）、目标较明显（0.6/0.3/0.1）、无车辆、同距离双车辆、杂波伪峰和超量程车辆。与任何检测结果无关地固定这些配置，不能挑选增益最大的模拟参数作为唯一报告。

多项式独立采样只作为首阶段统计假设，不代表设备回波独立性已得到验证。

## 接口和可视化交付

- 输入：图像尺寸、原图坐标车辆框、几何配置、回波配置及随机种子；可选真实红外图像。
- 输出：整数 counts_256/counts_128、距离边界、有效性与异常统计、完整模拟配置和数据来源标识。
- 中间几何信息独立存放用于诊断，不能作为后续模型的额外标签输入。
- 图表：原图和车辆框（或明确标注的合成示意图）、地面几何俯视图、200 次采样直方图；区分车辆/地面/杂波的期望分布与实际采样计数。
- 不同图像和变体的种子稳定记录；在生成变体之前完成源图像或序列的数据划分。

## 验收

1. 中心射线算例与解析值一致；左右对称像素在当前几何下距离相等。
2. 无效射线及超量程车辆按上述规则处理，且不污染图像标签。
3. 每次输出形状符合要求，计数为非负整数，总和严格为 200。
4. 128 桶计数严格等于相邻 256 桶合并，种子及配置相同可复现。
5. 无车辆、同距离目标与背景主导场景均能生成；不能把峰个数当作车辆数量。
6. 使用合成示意完成几何验收不构成红外或融合检测性能证据。
