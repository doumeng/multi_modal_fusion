# Infrared–Radar Feature Fusion

无人机倾斜下视场景下，研究红外图像与毫米波雷达距离直方图的特征级融合，用于地面车辆检测与跟踪。

## 当前状态

项目目前处于研究设计与实施计划阶段。尚未实现模拟器、下载数据集或训练检测/跟踪模型。

## 数据路线

- **统计模拟**：从假设几何、车辆和背景分布中生成 200 个回波的距离计数直方图，支持 `[1,256]` 与 `[1,128]`。
- **实测点云代理**：拟核验 FlexSense 等真实配对红外与毫米波点云数据，按共同视场汇聚距离分布，再单独生成固定 200 个计数的重采样版本。

统计模拟与点云重采样均不等同于实际设备的原始回波；路侧数据实验不能直接证明无人机场景的真实融合性能。

## 首阶段仿真假设

| 参数 | 默认值 |
| --- | --- |
| 无人机高度 | 60 m |
| 相对水平面的下视角 | 45° |
| 相机水平视场角 | 60° |
| 距离范围 | [0,256) m |
| 回波计数 | 每个有效模拟周期 200 |
| 分辨率 | 256 桶；相邻合并为 128 桶 |

上述参数用于受控验证，不代表实测标定。
